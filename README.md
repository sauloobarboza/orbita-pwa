# FLOW Elite
**Organize. Priorize. Conclua.**

PWA pessoal para organizar vida pessoal e profissional. Aplicação local-first, sem Supabase e sem backend.

## Módulos
- Visão geral, Meu dia, tarefas com lista/Kanban, projetos e agenda.
- Minha vida: casa, família, finanças pessoais, estudos, bem-estar e objetivos.
- Workspace: Scrum, sprints, histórias, reuniões, impedimentos.
- BPC: processos, requisitos, critérios de aceite e rastreabilidade.
- Indicadores, notas, busca global, backup e restauração JSON.

## Privacidade e limites
Os registros ficam no IndexedDB do navegador neste dispositivo. Não há sincronização automática entre dispositivos. Exporte backups regularmente. Não armazene senhas, dados pessoais de clientes ou informações corporativas confidenciais.

A migração do Órbita, quando possível, importa alguns registros locais legados sem apagar a chave antiga. Dados de outros navegadores/dispositivos não são acessíveis automaticamente.

## Publicação
O repositório usa GitHub Pages. Após o primeiro carregamento online, o shell do app pode funcionar offline. Recursos externos de fontes podem não carregar sem conexão.
