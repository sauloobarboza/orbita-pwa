# Órbita — sua rotina

Aplicativo PWA independente para hábitos, metas, notas e calendário. Os dados ficam salvos localmente no navegador (`localStorage`); não usa Supabase nem banco remoto.

## Publicação
O site é servido pelo GitHub Pages. Para instalar no celular, abra o endereço HTTPS no navegador e use **Adicionar à tela inicial**.

## Privacidade e backup
Os dados permanecem neste dispositivo e neste navegador. Use a opção de exportar backup JSON regularmente. Limpar os dados do navegador pode apagar os registros.
